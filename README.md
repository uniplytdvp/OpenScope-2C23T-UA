# OpenScope-2C23T-UA — Кастомна прошивка для FNIRSI 2C23T (Українська локалізація + Розширений DMM)

Кастомна відкрита прошивка для портативного комбінованого приладу **FNIRSI 2C23T** (мультиметр, двоканальний осцилограф та генератор сигналів) із повною підтримкою **української мови**, розширеною статистикою мультиметра (**MIN / MAX / MAX-MIN**) та адаптованим збиранням під **Windows**.

> ⚠️ **Увага:** Прошивка в розробці. Ви використовуєте її на власний ризик. Перед першим прошиванням обов'язково ознайомтеся з розділом вибору апаратної ревізії (`<HW4.0` або `HW4.0`).

## Що додано в цьому репозиторії (OpenScope-2C23T-UA)

До можливостей офіційної прошивки (станом на реліз **v2026.11.3**) у цій версії додано:

1. **Мультимовний інтерфейс (Українська / Англійська):**
   - Усі текстові рядки інтерфейсу винесені в окремий модуль локалізації (`src/i18n.h`, `src/i18n.c`), що дозволяє легко підтримувати та додавати нові мови.
   - Перемикання мови (`LANGUAGE` / `МОВА`: `ENGLISH` / `УКРАЇНСЬКА`) доступне безпосередньо в меню налаштувань (`Settings` / `НАЛАШТУВАННЯ`).

2. **Кириличний знакогенератор та спеціальні символи (`src/font.c`, `src/display.c`):**
   - Додано векторно-растрові гліфи українського алфавіту (`А–Я`, включно з `І`, `Ї`, `Є`, `Ґ`) для всіх трьох масштабів шрифту.
   - Додано підтримку малих літер-префіксів одиниць вимірювання (`m` — мілі, `n` — нано, `µ` — мікро) та спецсимволів (`Ω` — Ом, `°` — градус).

3. **Локалізація та стандартні одиниці мультиметра (DMM):**
   - Уніфіковано та стандартизовано міжнародні позначення одиниць вимірювання для всіх мов: `V`, `mV`, `A`, `mA`, `µA`, `Ω`, `kΩ`, `MΩ`, `F`, `mF`, `µF`, `nF`, `°C` (забезпечує однозначність сприйняття та збереження стандарту SI).
   - Перекладено службові стани та режими: `ОБРИВ` (`OPEN` для опору та продзвонки), `ФАЗА` (`LIVE` для безконтактного/контактного пошуку фази), `АВТО`.

4. **Статистика мультиметра в реальному часі (`MIN`, `MAX`, `MAX-MIN`):**
   - Під час вимірювання постійної/змінної напруги та струму (`DCV`, `ACV`, `DCA`, `ACA`, `DCmA`, `ACmA`, окрім режиму `AUTO`) під основним показником ліворуч постійно відображається компактний блок статистики: **МІН**, **МАКС** та розмах **МАКС-МІН**.
   - **Захист від нульових наведень:** відліки поблизу нуля (`|значення| <= 5` молодших розрядів) ігноруються, а фіксація мінімуму (`MIN`) починається лише після 3 стабільних ненульових вимірів поспіль, щоб уникнути помилкового запису нуля в момент дотику щупами.
   - **Керування кнопкою `CH1` у режимі мультиметра:**
     - **Коротке натискання `CH1`** — миттєве скидання (обнулення) накопиченої статистики `MIN / MAX`.
     - **Довге натискання `CH1`** — циклічне перемикання головного великого індикатора між режимами:
       `Миттєве значення (LIVE)` $\rightarrow$ `МІН (MIN)` $\rightarrow$ `МАКС (MAX)` $\rightarrow$ `МАКС-МІН (MAX-MIN)` $\rightarrow$ `Миттєве значення (LIVE)`.

5. **Кросплатформний скрипт збирання для Windows (`build.py`):**
   - Додано Python-скрипт для безпроблемного збирання обох ревізій прошивки в середовищі Windows без потреби у специфічних утилітах Linux.

## Основні можливості прошивки OpenScope-2C23T

Окрім стандартних функцій мультиметра, осцилографа та генератора сигналів, прошивка містить:

- **Тема High-Contrast Pro (v2026.11.3):** глибокий чорний фон OLED-стилю, яскравий золотий колір CH1, неоновий блакитний CH2 та підвищена контрастність тексту.
- **USB Composite (Mass Storage + Віртуальний COM-порт CDC ACM):**
  - Одночасний доступ до Flash-диска приладу (скріншоти, завантаження CSV, оновлення прошивки) та потокова передача телеметрії через USB Serial (`$DMM,...`, `$SCOPE,...`, `$WAVE,...`).
  - Віддалене керування приладом із ПК командами через COM-порт (`MODE:DMM`, `MODE:SCOPE`, `SCOPE:RUN`, `SCOPE:STOP`, `SCOPE:AUTO`, `SCOPE:TB:+/-`, `SCOPE:CH1:+/-`).
- **Аналітичне меню осцилографа (довге натискання `CH1` в осцилографі):**
  - Справжній розрахунок **True RMS** за вибірками сигналу.
  - Математичні операції між каналами, режим **XY**, приховування променів.
  - **Спектроаналізатор (FFT)** з вибором віконних функцій та режимів усереднення / фіксації піків (Max-Hold).
  - Побудова АЧХ (**Bode Plot**).
- **Розширений генератор сигналів:**
  - **вбудовані форми сигналу:** синус, меандр, трикутник, пила, напівхвиля, повна хвиля, шум, постійний струм (DC), сходинка, експонента, мультитон, імпульс Сінкера, імпульс Лоренца.
  - **Довільні форми сигналу (Arbitrary CSV):** відтворення користувацьких таблиць до 2048 точок із файлів `.csv` у корені USB-диска.
  - **Меню модуляції та качання частоти (довге натискання `CH1` у генераторі):** лінійний/логарифмічний **Sweep** та частотна модуляція (**FM**).
- **Збереження скріншотів** у форматі `.BMP` на вбудований накопичувач та **безпечний експорт Bootloader** із перевіркою CRC32.

## Нюанси збирання під Windows

Оригінальний `Makefile` розрахований на середовище Linux / macOS і використовує shell-команди POSIX (`uname -s`, `mkdir -p`, `rm -rf`, `find`), через що запуск звичайного `make` у Windows PowerShell або CMD завершується помилкою.

### 1. Необхідні інструменти для Windows
Для компіляції прошивки під Windows достатньо встановити лише два пакети:
1. **Python 3.8+** (`python` має бути доданий у системну змінну `PATH`).
2. **LLVM (Clang + LLD)** — завантажити інсталятор `LLVM-*-win64.exe` з офіційної сторінки [LLVM Releases](https://github.com/llvm/llvm-project/releases) і під час встановлення обрати пункт **"Add LLVM to the system PATH"**.
   - Жоден окремий `arm-none-eabi-gcc` не потрібен: штатний `clang` із пакету LLVM має вбудовану підтримку крос-компіляції `-target armv7em-none-eabi` та лінкера `ld.lld`.

Перевірити наявність інструментів у PowerShell:
```powershell
clang --version
python --version
```

### 2. Збирання прошивки (рекомендований спосіб для Windows)
У корені проекту виконайте команду:
```powershell
python build.py
```
Скрипт `build.py` автоматично:
- створює робочі директорії `build/lt-hw4` та `build/hw4.0`;
- налаштовує скрипти лінкера (`linker.ld`) під відповідні адреси завантажувачів та розміри Flash-пам'яті;
- компілює весь вихідний код із прапорцями апаратного FPU Cortex-M4 (`-mcpu=cortex-m4 -mfpu=fpv4-sp-d16 -mfloat-abi=softfp -Oz`);
- лінкує `.elf` та конвертує його за допомогою `tools/elf2bin.py` у готові бінарні файли в папці `dist/`:
  - `dist/F2C23T-v2026.11.3-08008000.bin` (для плати `<HW4.0`)
  - `dist/F2C23T-v2026.11.3-HW4.0-08007000.bin` (для плати `HW4.0`)

### 3. Запуск модульних тестів під Windows
Якщо у вас встановлено **Git for Windows**, до його складу входить середовище **Git Bash**, яке має всі необхідні POSIX-утиліти для виконання тестів із `Makefile`. Запустити всі 16 регресійних тестів можна командою з PowerShell:
```powershell
& "C:\Program Files\Git\bin\bash.exe" -c "make test"
```

## Встановлення прошивки на прилад

### Крок 1. Визначте вашу апаратну ревізію
Існує дві основні апаратні ревізії FNIRSI 2C23T:
- **`<HW4.0` (старіша ревізія):** використовуйте файл **`F2C23T-v2026.11.3-08008000.bin`**, якщо ваш прилад з заводу мав прошивку **старішу за `2.1.0`**.
- **`HW4.0` (новіша ревізія):** використовуйте файл **`F2C23T-v2026.11.3-HW4.0-08007000.bin`**, якщо ваш прилад прийшов із заводською прошивкою **`2.1.0`** (або вже працював на ній).

### Крок 2. Прошивання через вбудований завантажувач (Bootloader)
1. Вимкніть прилад.
2. Затисніть і утримуйте кнопку **`MENU`**.
3. Утримуючи `MENU`, натисніть кнопку **Живлення (Power)**.
4. Підключіть прилад кабелем USB до комп'ютера — з'явиться новий USB-накопичувач.
5. Скопіюйте відповідний `.bin` файл на цей накопичувач.
6. Дочекайтеся завершення копіювання та автоматичного запису прошивки, після чого перезапустіть прилад.

*(Також підтримується оновлення прямо з увімкненої кастомної прошивки: підключіть USB у звичайному режимі, скопіюйте `.bin` файл на диск приладу та безпечно вийміть накопичувач).*

### Резервне копіювання завантажувача (Bootloader Backup)
Рекомендується одразу після встановлення прошивки зберегти дамп вашого рідного бутлоадера:
1. Відкрийте **`НАЛАШТУВАННЯ` (`Settings`)** $\rightarrow$ оберіть **` ЗАВАНТ. / ЕКСПОРТ` (`BOOTLOADER / EXPORT`)** $\rightarrow$ натисніть **`OK`**.
2. У корені USB-диска приладу з'являться файли `boot_old.bin` + `boot_old.txt` (32 КБ) або `boot_hw4.bin` + `boot_hw4.txt` (28 КБ) із контрольною сумою CRC32. Скопіюйте їх у надійне місце на ПК.
